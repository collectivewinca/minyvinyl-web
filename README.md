# MinyVinyl Web

Web front-end project for MinyVinyl product/site development.

## Purpose

This repository is used to build and iterate on the MinyVinyl web experience.

## Expected Experience

- Developer-friendly local iteration
- UI and content updates with quick feedback
- Simple path to preview and deployment testing

## Getting Started

```bash
npm install
npm run dev
```

## Notes

A StackBlitz link may be used for quick cloud editing, but local development is recommended for full control.
